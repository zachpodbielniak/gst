* GST - GObject Simple Terminal
:PROPERTIES:
:CUSTOM_ID: gst---gobject-simple-terminal
:END:
A GObject-based terminal emulator with modular extensibility. GST is a reimplementation of [[https://st.suckless.org/][st (suckless terminal)]] using GObject for clean architecture and a plugin-based module system to replace st's patch-based customization.

** Features
:PROPERTIES:
:CUSTOM_ID: features
:END:
- *GObject Architecture*: Clean separation between terminal emulation, rendering, and windowing
- *Module System*: GModule-based plugins with well-defined hook points (replacing st's patches)
- *Dual Configuration*: YAML files for simple config, compiled C for advanced customization
- *X11 and Wayland*: Both backends supported with runtime auto-detection
- *libregnum (LRG) backend*: Optional 2D rendering through the libregnum/raylib game engine (=--lrg=, build with =LRG_BACKEND=1=) — see [[file:docs/lrg-backend.org][LRG Backend]]
- *GObject Introspection*: Full GIR support for language bindings

** Release 0.4.7
Complete Unicode clusters, primary live-grid reflow, history search and command-output actions, negotiated Kitty keyboard input, Wayland Compose/IME/scaling, and graphics/LRG integration are implemented. See [[file:docs/release-0.4.7.org][0.4.7 Release Notes]] for controls, verification evidence and explicit remaining limits.

*A clean rebuild of GST and all external modules is required*: the public =GstGlyph= layout changed. Existing saved history is not globally reflowed or pulled back on growth; this release does not claim full Kitty graphics/keyboard parity or completed manual IME/monitor validation.

** Building
:PROPERTIES:
:CUSTOM_ID: building
:END:
*** Dependencies
:PROPERTIES:
:CUSTOM_ID: dependencies
:END:
- glib-2.0, gobject-2.0, gio-2.0, gmodule-2.0
- x11, xft, xrender, fontconfig
- libyaml (yaml-0.1), json-glib-1.0
- pango, harfbuzz
- gcc (gnu89)
- gobject-introspection (optional, for GIR generation)

Fedora packages for the base build: =gcc make pkgconf-pkg-config glib2-devel libX11-devel libXft-devel libXrender-devel fontconfig-devel freetype-devel libyaml-devel json-glib-devel pango-devel harfbuzz-devel=. GIR generation additionally needs =gobject-introspection-devel=. Initialize the =yaml-glib= and =crispy= submodules.

Wayland adds =wayland-devel libxkbcommon-devel cairo-devel libdecor-devel=; protocol regeneration and Compose tests use =wayland-protocols-devel xkeyboard-config=. LRG adds =mesa-libGL-devel cairo-devel= and initialized libregnum/graylib/raylib submodules. MCP adds =libsoup3-devel libdex-devel libpng-devel= and the mcp-glib submodule; WEBVIEW adds =libsoup3-devel=. Include packages in the OS image on immutable Fedora systems. See [[file:docs/backend-testing.org][backend testing]] for fonts and isolated graphical-test dependencies.

*** Build Commands
:PROPERTIES:
:CUSTOM_ID: build-commands
:END:
#+begin_src sh
make              # Build all (lib, gst, modules)
make lib          # Build static and shared libraries
make gst          # Build the gst executable
make gir          # Generate GIR/typelib
make modules      # Build all modules
make test         # Run the test suite
make install      # Install to PREFIX
make DEBUG=1      # Build with debug symbols
make LRG_BACKEND=1 # Build with the libregnum (LRG) 2D backend (--lrg)
#+end_src

Optional build flags: =BUILD_WAYLAND=0= (X11-only), =LRG_BACKEND=1=
([[file:docs/lrg-backend.org][libregnum backend]]), =MCP=1=, =WEBVIEW=1=.

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
#+begin_src sh
gst                          # Start with default shell
gst -e htop                  # Run htop
gst -g 120x40                # Start with 120 columns, 40 rows
gst -f 'JetBrains Mono:14'   # Use specific font
gst -c ~/.config/gst/my.yaml # Use custom config
gst --x11                    # Force X11 backend
gst --wayland                # Force Wayland backend
gst --lrg                    # libregnum (LRG) 2D backend (LRG_BACKEND=1 build)
#+end_src

See [[file:docs/cli.org]] for the complete CLI reference.

** Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:
Generate a default config file:

#+begin_src sh
gst --generate-yaml-config > ~/.config/gst/config.yaml
#+end_src

Configuration files are searched in this order:

1. =--config PATH= (command line override)
2. =~/.config/gst/config.yaml=
3. =/etc/gst/config.yaml=
4. =/usr/share/gst/config.yaml=

GST also supports a C configuration file for advanced customization (compiled automatically at startup). See [[file:docs/c-config.org]] for details.

See [[file:docs/configuration.org]] for the complete configuration reference.

** Modules
:PROPERTIES:
:CUSTOM_ID: modules
:END:
Modules are loaded from:

1. =$GST_MODULE_PATH= (environment variable, colon-separated)
2. =~/.config/gst/modules/=
3. =/etc/gst/modules/=
4. =/usr/share/gst/modules/=

** Architecture
:PROPERTIES:
:CUSTOM_ID: architecture
:END:
#+begin_example
gst/
├── src/
│   ├── core/           # Terminal emulation
│   ├── rendering/      # Abstract renderer + X11/Wayland/LRG implementations
│   ├── window/         # Abstract window + X11/Wayland/LRG implementations
│   ├── config/         # YAML configuration
│   ├── module/         # Module system
│   ├── selection/      # Selection and clipboard
│   ├── boxed/          # GBoxed types (glyph, cursor)
│   ├── interfaces/     # Module hook interfaces
│   └── util/           # UTF-8, base64 utilities
├── modules/            # Built-in modules
├── tests/              # GTest unit tests
└── data/               # Default config and color schemes
#+end_example
